> [!IMPORTANT]
> **This is a fork, not the official PocketMine-MP.**
> This repository is [axolotl-pm/PocketMine-MP](https://github.com/axolotl-pm/PocketMine-MP), a fork of the legacy [pmmp/PocketMine-MP](https://github.com/pmmp/PocketMine-MP) project. The original repository was archived by the PMMP team on 9 July 2026 and no longer receives updates. This fork is maintained by the Axolotl-PM Team and continues the project. It is not the upstream PMMP release.

> [!CAUTION]
> **PocketMine-MP is NOT a vanilla Minecraft server software.** It is poorly suited to hosting vanilla survival servers. It lacks many vanilla features, such as vanilla world generation, redstone, and mob AI. For vanilla survival multiplayer, use the [official Minecraft: Bedrock server software](https://minecraft.net/download/server/bedrock) instead.

## About

PocketMine-MP is a highly customisable server software for Minecraft: Bedrock Edition, built in PHP, with over 10 years of history. The PMMP team announced the end of support for the original project in July 2026. Axolotl-PM is made up of contributors who have been part of the PocketMine-MP ecosystem for over 5 years, and this fork carries the project forward.

If you want a Minecraft: Bedrock server with **custom functionality**, this is built for that.

## Developing Plugins

If you want to write your own plugins, these resources may help. You can always ask the community if you get stuck.

- [Developer documentation](https://axolotl-pm.org/docs/developers/plugin-docs-index): general documentation for plugin developers
- [Latest release API documentation](https://apidoc.pmmp.io): Doxygen docs generated for each release of the original project
- [DevTools](https://github.com/pmmp/DevTools/): development tools plugin for creating plugins
- [ExamplePlugin](https://github.com/pmmp/ExamplePlugin/): example plugin demonstrating basic API features
